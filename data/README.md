CropCare AI – Dataset Information

This project uses publicly available plant disease image datasets and additional images for model development, testing, and evaluation.

Datasets Used

- PlantVillage – Plant leaf images for crop disease classification.
- PlantVillage 38-Class Dataset – Multi-class crop disease image dataset.
- PlantWild – Plant disease images collected in more diverse, real-world conditions.
- Custom.ai Dataset – Additional images used for project development.
- Tomato Dataset – Tomato leaf images used for disease analysis and testing.
- Test Images – Sample images used to test the application and predictions.

Dataset Purpose

The datasets were used for training, fine-tuning, testing, and evaluating image-based crop disease classification models.

Dataset Availability

The complete datasets are not included in this repository because of their size. Users should obtain datasets from their respective original sources and follow the licensing and usage terms.

Sample images may be included separately for demonstration purposes.
